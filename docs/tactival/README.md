# TactiVal の座標合わせ

同梱済みの座標合わせ（`vreplay/data/tactival_calib.json`）

| マップ | 状態 |
|---|---|
| Split | 4 点・ずれ 36px・**回転 92.9 度**（アプリのマップが回っています） |
| Sunset | 4 点・ずれ 37px・回転 5.7 度 |

ほかのマップ、または精度を上げたいときは下の手順で合わせてください。

**座標合わせ用のボードは、どのマップでもコマンドで作れます。**

```bash
vreplay tactival --board --map Haven
```

`output.dir/tactival_calib_haven.json` が出ます（すでに合わせてあるマップは、その位置に駒を置くので
ドラッグはほぼ不要）。このフォルダの `calib-split` / `calib-sunset` は、その出力をそのまま置いたものです。

TactiVal（作戦ボードのアプリ）のマップはベクター画像で、valorant-api の座標とは原点も倍率も違います。
マップごとに 1 回だけ、次の手順で合わせてください。

1. このフォルダの `calib-<マップ>.tactival.json` を TactiVal で読み込む
2. 4 体の駒を、それぞれ正しい場所へドラッグする

   | エージェント | 置く場所 |
   |---|---|
   | Jett | 攻撃側スポーン |
   | Sage | 防衛側スポーン |
   | Omen | A サイト（設置点のあたり） |
   | Viper | B サイト |
   | Cypher | C サイト（3 サイトのマップだけ） |

3. JSON で書き出して、次を 1 回実行する（`--board` で作ったボードでも、手で作ったボードでも可）

   ```bash
   vreplay tactival --calibrate <書き出した.json> --map Sunset
   ```

倍率と原点が `output.dir/_cache/tactival_calib.json` に記録され、以降 `vreplay playbook` が
型ごとの TactiVal ボードを `playbook/tactival/` に書き出します。

- 3 体以上あれば**アフィン変換（回転・鏡映・縦横の倍率）**で合わせます。TactiVal のマップは
  valorant-api の画像に対して回っていることがあり（**Split は 90 度**）、倍率と原点だけでは合いません。
  2 体だけのときは回転を見られないので、必ず 3 体以上置いてください。
- 駒の `x`/`y` はアイコンの左上なので、中身では真ん中に直してから計算しています。
- ここに置いてあるボードの初期位置は推定値です。正しい場所にドラッグしてから書き出してください。

## 矢印

型ごとの「どこからどこへ」（`deck.row_arrows`）を矢印で書き出します。形式はアプリの書き出しから
分かったもので、始点が `x`/`y`、終点が `data.x2`/`data.y2`、`width`/`height` は差の絶対値です。

- デフォルト：キーエリア → よく行くサイト
- 捨て〜スプリット：見せた場所 → 本命のサイト
- 後取り：取り返す場所 → サイト
- ラッシュ／execution：1:15 の場所 → サイト
- リテイク：外のエリア → 設置されたサイト

色や太さを変えたいときは、好みの矢印を 1 本引いたボードを書き出して `tactival.template` に
指定してください。その見本の見た目を引き継ぎます（駒への結びつきは外します）。
