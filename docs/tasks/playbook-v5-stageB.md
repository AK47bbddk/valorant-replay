## 目的
v5 の構成ページの説明を、位置クラスタの型から「序盤→中盤→終盤の応酬の流れ」に作り替える。図は1枚1時刻の Tactival ボード3枚にし、文面はフェーズの言葉で組み直す。

## やること

### 1. ページ構成の組み替え（`vreplay/playbook_v5.py`）
- 構成ページを「なぜこの構成か（基本配置・役割表は現行維持）」＋「序盤」「中盤」「終盤」の3部構成にする。
- 各部には、その区間の型を件数順に並べる。各型に: 件数・勝率・流れ要約つきの代表ラウンド（複数件）・該当ラウンド集へのリンク（VODカード）。
- 型の判定は `phases.classify_flow` を使う。位置クラスタによる従来の手札スライドは、この3部の型表示に置き換える（基本配置の図と説明は残す）。
- 分母の扱い: フェーズ型は tracks のあるラウンドだけが基盤。ページ内に「分類できたラウンド数／全ラウンド数」を明示し、基本配置など全ラウンド基盤の数字と混ぜない。

### 2. 3枚図（序盤・中盤・終盤）
- 型の代表ラウンドについて、区間ごとの配置図を3枚（序盤・中盤・終盤）並べる。1枚につき1時刻のみ（時間経過の重ね描きはしない）。
- 図は既存の `board_img` 経路（ボードJSON→本物の Tactival で画像化）で作る。駒は Tactival のアイコン表示になること（文字略号の自前描画にしない）。
- 時刻の既定: 序盤＝区間の代表サンプル（開幕後最初の安定サンプル）、中盤＝区間中央、終盤＝プラント直後。区間が無いラウンド（プラント無し等）はある区間だけ出す。
- Tactival の画像化が実行環境でできない場合は、ボードJSONを成果物として残し、図の場所にその旨を明示する（旧来の重ね描き図への無言のフォールバックはしない）。
- 「なぜこの構成か」の図にも同じ3枚方式を適用する（叩き台 §8）。

### 3. 文面の作り替え
- ノード表（`glossary_word` 系、v4由来の「人数有利なら距離を詰める」「前に出て間合いを詰める」等）で文を組み立てる方式をやめ、フェーズの型と流れ要約から説明文を組み立てる。
- 型の説明は「アクション→リアクション」の形で書く（例: ピックを取った側がどう動いたか、それに相手がどう応じたか）。
- クレーム文の不自然な組み立て（「〜の勝率◯%…はまると強い」式）は廃止する。根拠の提示は現行の「全体との差」の形式を維持する。
- 表示変換の原則は維持: 略号・設計用語をそのまま出さない。守りの型に攻め向けの言葉を混ぜない（v5-fixes 2巡目の教訓）。

### 4. 実プレイ例の GIF・VOD
- GIF（アニメーション）は実際のプレイ例だけに使う。代表ラウンドには VOD サムネイルカードを必ず付け、生成ページに GIF が実際に貼られていることを検証項目に入れる（現行ページで GIF が貼られていない問題への対応）。
