# choke-cut-barrier-fix（分離できないチョークの切れ目を断面バリアにする）

※窓口 (Muse) が 2026-11-10 に作成。choke-segment-model の残課題2件の修正。青木の承認済み。

## 問題（切り分け済み）
- `vreplay/mapfig.py` の `_choke_radii` は、切れ目の円の半径に「両側の最寄りコールアウトを覆わない（距離 − 0.005）」上限がある。
- B Main|B Site のチョーク (0.113, 0.587) は B Main のコールアウト (0.138, 0.538) に近く、上限が約 0.05 になり、通路を断ち切れない。A Alley|A Site (0.899, 0.319) も上限約 0.063 で同様。
- 前回の実装はこの2件を不変条件テストから「既知の未解決」として除外した。今回は除外を撤廃し、全ペアで分離を必須にする。

## やること
1. 円で分離できないチョークについて、断面バリアで切る:
   - 両側の最寄りコールアウト同士を結ぶ経路（通路上の最短路）を取り、その経路上でチョーク点に最も近い点をバリア中心にする。
   - バリアは、その点で経路の進行方向に垂直な線分とし、両端が通路の外（壁）に届くまで伸ばす（＋数 px の余裕）。これを切れ目として使う。
   - 円で分離できるチョークは今の円のままでよい（効いている5件を壊さない）。バリアへの切替条件は「円の上限まで広げても両側が別区画にならないこと」。
2. 不変条件テストの除外を全て外す: ペアのあるチョーク（同一エリア同士を除く6件）すべてについて「全ての切れ目を入れた状態で、両側の最寄りコールアウトが別区画」を必須にする。分離できない場合はテストが落ちる形にする（黙って通さない）。
3. サイト側区画への入口エリアの食い込み検査（既存）も全チョーク対象のまま維持する。
4. 既存テスト（test_kb / test_playbook_v4 / test_gamemodel / test_tactival / test_meta / test_deck / test_mapfig / test_tactics）を全て通す。Sunset の領域図を _review/ に再作成する。
